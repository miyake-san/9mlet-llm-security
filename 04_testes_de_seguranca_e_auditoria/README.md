# Aula 04 — Testes de Segurança e Auditoria em LLMs

> **Status:** 🏗️ Estrutura criada — conteúdo prático a ser adicionado.

## Objetivo
Automatizar *red teaming* e auditoria de segurança de LLMs, integrando os testes ao pipeline CI/CD.

## Tecnologias
- **Microsoft PyRIT** + **NVIDIA Garak** + **promptfoo** (red teaming em CI/CD)
- **Azure Monitor** + **Application Insights** + **Azure Sentinel** (SIEM)
- Trilhas imutáveis: **WORM / hash chains**; severidade **CVSS-AI**

## Caso de negócio
Ciclo PAIR e relatório executivo de red team para o **Aurora Assist**.
