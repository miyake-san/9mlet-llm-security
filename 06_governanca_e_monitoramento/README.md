# Aula 06 — Governança de Dados e Monitoramento de LLMs

> **Status:** 🏗️ Estrutura criada — conteúdo prático a ser adicionado.

## Objetivo
Operar observabilidade contínua, detecção de *drift* e governança de dados em produção (LLMOps).

## Tecnologias
- **Evidently AI** (observabilidade ML/LLM, detecção de drift)
- **Langfuse** (tracing por step: latência, tokens, custo)
- **OpenTelemetry**; **Azure Workbooks** + **Grafana** (dashboards)

## Caso de negócio
Monitoramento contínuo de qualidade, custo e segurança do **Aurora Assist**.
