# Aula 02 — Guardrails e Políticas para LLMs

> **Status:** 🏗️ Estrutura criada — conteúdo prático a ser adicionado.

## Objetivo
Projetar e implementar guardrails de entrada, saída e comportamento com abordagem *policy-as-code* e *defense-in-depth*.

## Tecnologias
- **NVIDIA NeMo Guardrails** + linguagem **Colang**
- **Guardrails AI** (Rail Spec)
- **Llama Guard 3** (Meta)
- **Azure AI Content Safety** (AACS + Prompt Shield)
- Benchmarks: **HarmBench**, **AdvBench**

## Caso de negócio
Camadas de proteção do **Aurora Assist** contra prompt injection e conteúdo inseguro.
